Makefile简介

Makefile 是 make 工具读取的构建脚本文件，主要用于描述“哪些文件依赖哪些文件，以及如何从依赖生成目标文件”。
它最早出现在 Unix/C 语言开发环境中，核心目的是自动化编译和增量构建。

Makefile 常用于：

编译 C/C++ 项目
链接可执行文件或库
自动运行测试
清理构建产物
打包、安装、部署
统一项目里的常用命令

Makefile基础

基础格式

在Linux环境下，当我们输入make命令时，它就在当前目录查找一个名为Makefile的文件，然后，根据这个文件定义的规则，自动化地执行任意命令，包括编译命令。

Makefile文件的基本格式:

target: dependencies
    command

举例如下:

project/
    main.h
    main.c
    Makefile

main.h

#ifndef MAIN_H
#define MAIN_H

void hello_world();

#endif

main.c

#include <stdio.h>
#include "main.h"

void hello_world() {
    printf("Hello world!");
}

int main() {
    hello_world();
    return 0;
}

Makefile

CC = gcc
TARGET = 1.exe

$(TARGET): main.o
    $(CC) main.o -o $(TARGET)

main.o: main.c main.h
    $(CC) -c main.c

run: $(TARGET)
    ./$(TARGET)

clean:
    rm -f $(TARGET) *.o

$ make
gcc -c main.c
gcc main.o -o 1.exe
$ make run
./1.exe
Hello world!

Makefile定义了一系列规则，每个规则在满足依赖文件的前提下执行命令，就能创建出一个目标文件。
把默认执行的规则放第一条，其他规则的顺序是无关紧要的，因为’make’执行时自动判断依赖。

如果再次执行make，则输出如下:
$make
make: ‘1.exe’ is up to date.

make检测到1.exe已经是最新版本，无需再次执行，因为1.exe的创建时间晚于它依赖的最后修改时间。

执行多条命令

一个规则可以有多条命令，例如：

cd:
    pwd
    cd ..
    pwd

执行cd规则：

$ make cd
pwd
/home/ubuntu/makefile_example/v1
cd ..
pwd
/home/ubuntu/makefile_example/v1

观察输出，发现cd ..命令执行后，并未改变当前目录，两次输出的pwd是一样的，这是因为make针对每条命令，都会创建一个独立的Shell环境，类似cd ..这样的命令，并不会影响当前目录。

解决办法是把多条命令以;分隔，写到一行：

cd_ok:
    pwd; cd ..; pwd;

再执行cd_ok目标就得到了预期结果：

$ make cd_ok
pwd; cd ..; pwd
/home/ubuntu/makefile_example/v1
/home/ubuntu/makefile_example

可以使用\把一行语句拆成多行，便于浏览：

cd_ok:
    pwd; \
    cd ..; \
    pwd

另一种执行多条命令的语法是用&&，它的好处是当某条命令失败时，后续命令不会继续执行：

cd_ok:
    cd .. && pwd

控制

默认情况下，make会打印出它执行的每一条命令。如果我们不想打印某一条命令，可以在命令前加上@，表示不打印命令（但是仍然会执行）

make在执行命令时，会检查每一条命令的返回值，如果返回错误（非0值），就会中断执行。

如删除不存在的文件

has_error:
    rm a.txt
    echo 'ok'

输出如下:

$ make has_error
rm a.txt
rm: a.txt: No such file or directory
make: *** [has_error] Error 1

有些时候，我们想忽略错误，继续执行后续命令，可以在需要忽略错误的命令前加上-。

Makefile
no_error:
    -rm a.txt
    echo 'ok'

输出如下:

$ make has_error
rm a.txt
rm: a.txt: No such file or directory
make: *** [has_error] Error 1 (ignored)
echo 'ok'
ok
